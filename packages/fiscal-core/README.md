# Fiscal Core

Dominio fiscal independiente de TicketBAI concreto.

Responsabilidades previstas:

- Emisores fiscales.
- Series y numeracion.
- Facturas fiscales inmutables.
- Anulaciones, rectificaciones y auditoria.
- Estados fiscales y cola de envio.

Este paquete no debe depender de React ni de pantallas TPV/ERP.
