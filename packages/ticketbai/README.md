# TicketBAI

Adaptadores y logica especifica de TicketBAI/BATUZ.

Responsabilidades previstas:

- Generacion XML por territorio.
- Validacion contra XSD.
- Firma XAdES.
- Generacion de identificativo y QR.
- Envio a Araba, Gipuzkoa o Bizkaia/BATUZ.
- Tratamiento de respuestas y errores.

Debe mantenerse aislado del ERP y del TPV para poder sustituirlo por un proveedor/SDK fiscal si conviene.
