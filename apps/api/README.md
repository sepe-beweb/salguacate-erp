# Salguacate API

Backend Express actual de la plataforma Salguacate.

Responsabilidades actuales:

- API del ERP.
- Autenticacion y permisos.
- Base de datos SQLite/Turso.
- Integraciones de IA.
- Persistencia de inventario, proveedores, usuarios, turnos, cierres y tareas.

La futura logica TPV y fiscal debe entrar en modulos separados antes de mezclarse con endpoints existentes.
