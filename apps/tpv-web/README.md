# Salguacate TPV Web

Espacio reservado para el futuro TPV de Salguacate.

Responsabilidades previstas:

- Mesas, barra y comandas.
- Productos vendibles y modificadores.
- Cobros efectivo/tarjeta/mixtos.
- Sesiones de caja y cierres TPV.
- Emision de tickets/facturas a traves del modulo fiscal.
- Sincronizacion de ventas y consumo con el ERP.

El TPV no debe implementar TicketBAI directamente. Debe consumir una API fiscal estable.
